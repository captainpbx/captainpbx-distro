# Paging

**Voice** menu. Inside an organization.

Paging is an announcement, not a conversation. Use a ring group when you need someone to answer.

## Do this

1. Open **Voice → Paging**.
2. Give the page a number and choose the extensions that should hear it.
3. Save, then run **Sync & Apply**.
4. Dial the page number from a phone. Those extensions play the announcement.

## You are done when

Dialing the page number speaks on the phones in the group.
