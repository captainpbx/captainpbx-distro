# Music on Hold

**Audio** menu. Inside an organization.

You can use the built-in audio or add your own. Queues and phones on hold use the class you select.

## Do this

1. Open **Audio → Music on Hold**.
2. Add a class or choose the existing one, and add the audio files.
3. Save, then run **Sync & Apply**.
4. Place a call on hold, or into a queue that uses this class, and listen.

## You are done when

The caller hears that audio while waiting.
