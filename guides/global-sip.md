# Global SIP Settings

**Platform** menu. System view.

Change this when the provider or the network needs a different SIP port or a different global option. Day-to-day extensions do not live here.

## Do this

1. Stay in the system view.
2. Open **Platform → Global SIP Settings**.
3. Change only the value you were asked to change.
4. Save, then run **Sync & Apply**.

## You are done when

Phones still register, and the new setting is the one in use.
