# EndpointWatch

**Home** menu. Inside an organization.

EndpointWatch is the phone list for this organization. A phone that is not registered cannot make or receive calls.

## Do this

1. Select the organization.
2. Open **Home → EndpointWatch**.
3. Find the extension. Registered means the phone has signed in. Missing means the phone is off, or the SIP account is wrong.
4. Open alert rules only if you want an email or a notice when a phone stays down. Save the rule when you change it.

## You are done when

The extension you just set up shows as registered after the phone signs in. Phone setup is in [Register a SIP phone](../sip-registration.md).
