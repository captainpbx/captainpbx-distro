# Browser phone

**Platform** menu. System view.

The person still needs an extension. The browser is just another phone on that extension.

## Do this

1. Open **Platform → Browser phone**.
2. Choose the extension this browser should register as.
3. Allow the browser to use the microphone.
4. Place a test call to another extension.

## You are done when

The browser shows registered, and the test call completes.
