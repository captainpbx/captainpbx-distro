# Queue Analytics

**Insights** menu. Inside an organization.

Open this after a queue has taken real calls. An empty queue has an empty report.

## Do this

1. Open **Insights → Queue Analytics**.
2. Choose the queue and the dates.
3. Read wait time, answered calls, and abandoned calls, and export if you need a file.

## You are done when

The numbers match the calls that waited in that queue.
