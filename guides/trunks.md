# Trunks

**Routes** menu. Inside an organization.

You need the provider's server, your username, and the password they gave you. Those are not the extension SIP passwords.

## Do this

1. Open **Routes → Trunks** and add the provider.
2. Enter the provider address, username, and password from the provider.
3. Save, then run **Sync & Apply**.
4. The trunk should show registered. Then add an outbound route so extensions can dial out, and an inbound route so their numbers ring in.

## You are done when

The trunk shows registered, and a test call in or out uses it.
