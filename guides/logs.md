# Logs

**Insights** menu. System view.

Logs are for the person running the whole appliance. They are in the system view, not inside an organization.

## Do this

1. Stay in the system view. Do not select an organization.
2. Open **Insights → Logs**.
3. Filter by the time of the problem and read the message.

## You are done when

You can find the message from the time the problem happened.
