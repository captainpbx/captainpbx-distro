# API tokens

**Platform** menu. Inside an organization.

Create a token only for a system you trust. If it leaks, delete it. Deleting it does not affect phone calls.

## Do this

1. Select the organization.
2. Open **Platform → API tokens**.
3. Create a token, copy it immediately, and store it in the script.
4. Delete a token you no longer use.

## You are done when

The script can call the API with that token, and a deleted token cannot.
