# Captain Trust

**System** menu. System view.

The first certificate is created for you, and the browser warns until you replace it with one for your real hostname.

## Do this

1. Open **System → Captain Trust**.
2. See the certificate in use.
3. Issue or upload one for the real hostname people type in the browser.
4. Open the website again and confirm the warning is gone.

## You are done when

The browser opens CaptainPBX on that hostname without a certificate warning.
