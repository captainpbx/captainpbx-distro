# Feature Codes

**Voice** menu. Inside an organization.

These are the star codes and short numbers a person dials during or before a call. The list shows the code and what it does.

## Do this

1. Open **Voice → Feature Codes**.
2. Read the code before you change it. Phones and printed cards may already use the current one.
3. Change a code only when you need a different number, then save and run **Sync & Apply**.

## You are done when

Dialing the code from an extension does what the list says, for example picking up a ringing phone.
