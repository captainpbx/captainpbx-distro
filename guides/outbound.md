# Outbound

**Routes** menu. Inside an organization.

A typical rule sends 10-digit and 11-digit numbers out the provider trunk. Internal extension dialing does not use this page.

## Do this

1. Open **Routes → Outbound**.
2. Add a rule for the numbers people dial, and choose the trunk.
3. Put the rule in the order you want it checked.
4. Save, then run **Sync & Apply**.

## You are done when

An extension can dial an outside number and the call leaves on that trunk.
