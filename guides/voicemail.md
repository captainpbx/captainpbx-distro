# Voicemail

**Media** menu. Inside an organization.

This admin page is the organization's voicemail. A person signed in to the portal hears only their own mailbox, even if they are an administrator.

## Do this

1. Open **Media → Voicemail**.
2. Open the extension, set the greeting, and turn the mailbox on if it is off.
3. Save, then run **Sync & Apply** so the phone's message light follows the mailbox.

## You are done when

Calling an extension that does not answer plays the greeting and can take a message.
