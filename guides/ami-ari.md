# AMI / ARI users

**Platform** menu. System view.

Most sites never add one. Add a user only when another system must watch or control calls.

## Do this

1. Stay in the system view.
2. Open **Platform → AMI / ARI users**.
3. Add a username and a strong password, and give it only the access that system needs.
4. Save, then run **Sync & Apply**. Store the password in that other system.

## You are done when

The other system can sign in with that username, and an unknown username cannot.
