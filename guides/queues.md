# Queue

**Queue** menu. Inside an organization.

Use a queue when calls should wait instead of ringing everyone at once. A ring group does not hold callers in a line.

## Do this

1. Open **Queue → Queue** and add a queue number.
2. Add the agent extensions and choose how calls are offered.
3. Set the greeting and the music callers hear while they wait.
4. Save, then run **Sync & Apply**. Point an inbound route or IVR key at this queue.

## You are done when

A call to the queue waits, then rings an agent who is logged in.
