# Captain Update Center

**System** menu. System view.

Read what an update changes before you apply it. Take a Vault backup first when the update is large.

## Do this

1. Open **System → Captain Update Center**.
2. Read the available updates.
3. Apply the one you want, and wait until it finishes.
4. Sign in again and confirm the menus you use still open.

## You are done when

The update shows as installed, and you can still sign in.
