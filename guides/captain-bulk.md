# Captain Bulk

**System** menu. System view.

Use this after one extension works the way you want. The list should use the same number pattern.

## Do this

1. Open **System → Captain Bulk**.
2. Choose what you are creating.
3. Provide the list and review it before you submit.
4. Run **Sync & Apply** when the new rows are phones or call routing.

## You are done when

The new extensions or people appear in their own menus.
