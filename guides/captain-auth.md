# Captain Auth

**Platform** menu. System view.

Turn on a second factor when a stolen password should not be enough to open CaptainPBX.

## Do this

1. Open **Platform → Captain Auth**.
2. Set the sign-in rules you want, such as a second factor.
3. Save. Sign out and sign back in once to confirm you still can.

## You are done when

You can sign in with the new rule, and a wrong second factor is refused.
