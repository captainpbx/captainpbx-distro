# Captain Shield

**System** menu. System view.

A phone with the right password still fails if Shield does not allow its address. Start here when registration never arrives.

## Do this

1. Open **System → Captain Shield**.
2. Allow the administrator's address for the website, and the phone network for SIP.
3. Apply the change. Do not remove the address you are using, or you can lock yourself out.
4. Confirm the phone registers after its address is allowed.

## You are done when

From an allowed network you can open the website, and an allowed phone can register.
