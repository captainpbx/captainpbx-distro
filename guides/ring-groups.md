# Ring groups

**Voice** menu. Inside an organization.

Use a ring group when a team shares one number, such as a front desk. The caller dials the group number, not each person.

## Do this

1. Open **Voice → Ring groups**.
2. Give the group a number and add the extensions that should ring.
3. Choose whether they ring at the same time or one after another, and what happens if nobody answers.
4. Save, then run **Sync & Apply**.

## You are done when

Dialing the group number rings the members you added.
