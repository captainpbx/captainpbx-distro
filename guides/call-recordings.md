# Call recordings

**Media** menu. Inside an organization.

Recording has to be turned on for the extension or the route before a file appears here. This page is for listening and downloading, not for turning recording on.

## Do this

1. Open **Media → Call recordings**.
2. Find the call by time or number.
3. Play it or download it.

## You are done when

The call you expected is in the list and plays.
