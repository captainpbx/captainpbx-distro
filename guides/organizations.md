# Organizations

**Platform** menu. System view.

Two organizations can both use extension 1001. The SIP domain is what keeps their phones apart. Create organizations here, then select one to configure its extensions.

## Do this

1. Stay in the system view.
2. Open **Platform → Organizations** and add one.
3. Set its name and SIP domain. The SIP domain can be the server's real hostname, or a separate name. It must be unique on this appliance.
4. Save, select that organization, and continue under Extensions.

## You are done when

The organization is in the list, and selecting it shows its own menu. Phone domains are explained in [Register a SIP phone](../sip-registration.md).
