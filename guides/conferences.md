# Conferences

**Voice** menu. Inside an organization.

People inside the organization dial the room number. A PIN is optional when you want the room closed.

## Do this

1. Open **Voice → Conferences** and add a room number.
2. Set a PIN if the room should not be open to every extension.
3. Save, then run **Sync & Apply**.
4. Dial the room from two extensions.

## You are done when

Both phones are in the room and can hear each other.
