# Sounds

**Audio** menu. Inside an organization.

Upload a file you already have, or record one. Give it a name you will recognize in the IVR list.

## Do this

1. Open **Audio → Sounds**.
2. Add a prompt, name it, and upload or record the audio.
3. Save. Choose this prompt on the IVR or announcement that should play it.
4. Run **Sync & Apply** after you attach it to a call flow.

## You are done when

The prompt appears in the list and plays when a caller reaches the menu or route that uses it.
