# Inbound

**Routes** menu. Inside an organization.

The outside number arrives on a trunk. This page chooses the destination: an extension, a ring group, an IVR, a queue, or voicemail. Business hours can send closed hours somewhere else.

## Do this

1. Open **Routes → Inbound**.
2. Match the number the provider sends you.
3. Choose the destination, and a closed-hours destination if you use a schedule.
4. Save, then run **Sync & Apply**.

## You are done when

Calling that outside number from a mobile rings the destination you chose.
