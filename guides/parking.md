# Parking

**Voice** menu. Inside an organization.

Parking is for 'please hold, I will take this at another desk.' The slot number is what the other phone dials.

## Do this

1. Open **Voice → Parking**.
2. Set the lot number and the range of slots.
3. Save, then run **Sync & Apply**.
4. On a live call, park it with the feature code, then dial the slot from another extension.

## You are done when

The parked call is picked up on the second phone and the first phone is free.
