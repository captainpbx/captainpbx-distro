# IVR

**Voice** menu. Inside an organization.

Record the greeting under Audio → Sounds first, then build the menu here.

## Do this

1. Open **Voice → IVR** and add a menu.
2. Choose the greeting callers hear.
3. Set each key: for example 1 goes to sales, 0 goes to the operator, and timeout goes to voicemail.
4. Save, then run **Sync & Apply**. Point an inbound route at this menu if outside callers should hear it.

## You are done when

Calling the menu plays the greeting, and each key lands on the destination you set.
