# Extensions

**Voice** menu. Inside an organization.

An extension is the number people dial, such as 1001. It is not the same thing as a web login. Saving an extension creates a SIP phone for it.

## Do this

1. Select the organization.
2. Open **Voice → Extensions** and add a number and a display name.
3. Save. Open the SIP phone on that extension and copy its SIP password. That password goes in the desk phone, not the web password.
4. Run **Sync & Apply** so the phone can register.

## You are done when

The number is in the list, the phone shows registered under EndpointWatch, and a call to another extension in the same organization rings. Fill in the phone with [Register a SIP phone](../sip-registration.md).
