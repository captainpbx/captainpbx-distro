# Captain Vault

**System** menu. System view.

Take a backup before a large change, and confirm you can see the backup file afterward.

## Do this

1. Open **System → Captain Vault**.
2. Run a backup.
3. Confirm the new backup is listed.
4. Download it if you keep a copy off the appliance.

## You are done when

A new backup is in the list and can be downloaded.
